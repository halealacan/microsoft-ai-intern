# AI Study Assistant

## Project Overview

AI Study Assistant is a web application that runs a local AI model using Microsoft Foundry Local and Phi-4 Mini.

The goal is to help university students study more efficiently by providing AI-powered assistance.

## Technologies

### Frontend
- React
- Vite

### Backend
- Python
- FastAPI

### AI
- Microsoft Foundry Local
- Phi-4 Mini

## Version 1 Features

- AI Chat
- Ask study-related questions
- Clean and modern interface
- Fast responses
- Local AI (no cloud API)

## Future Features

- PDF upload
- PDF summarization
- Quiz generation
- Flashcards
- Study planner
- Progress tracking

- Modern UI
